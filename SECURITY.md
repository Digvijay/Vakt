# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please follow these steps:

1.  **Do NOT open a public issue.**
2.  Email the security team at `security@example.com` or report via GitHub Security Advisories if enabled.
3.  Include a proof of concept (PoC) or detailed steps to reproduce the issue.
4.  We will respond within 48 hours with a confirmation and timeline for a fix.

Thank you for helping keep Project Vakt secure.
